6. `AutoGate`、`FocusSafeAutomation`、核准前檢查、ATTEMPT 先寫入及單次 Invoke 保持原樣。未知結果、OFF／ON、預算擴大均不清除已嘗試紀錄；不完整掃描仍不能證明按鈕已消失。
